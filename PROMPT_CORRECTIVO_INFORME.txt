 8. RECORDATORIO DEL CONTEXTO DEL PROYECTO
========================================================================

El proyecto es un prototipo académico de consola en Python 3, sin base
de datos ni librerías externas. La empresa es MG Bus, de Nueva Cajamarca.
El sistema permite ver viajes, mapa de asientos, vender, anular, deshacer
la última anulación, ver la lista de pasajeros, consultar rutas con
Warshall, ver las matrices del grafo, gestionar la cola de espera,
buscar por DNI, buscar ciudades y ver el reporte general.

Los archivos actuales son:

  main.py
  sistema.py
  clases.py
  consola.py
  validaciones.py
  datos_prueba.py
  README
  estructuras/nodo.py
  estructuras/lista_pasajeros.py
  estructuras/pila.py
  estructuras/cola.py
  estructuras/matriz_asientos.py
  estructuras/grafo_rutas.py
  estructuras/busquedas.py

No hay MVC ni DAO. No los menciones en el informe corregido. La
organización se explica simplemente como archivos con funciones
distintas: menú, operaciones y datos, clases, impresión en consola,
validaciones, estructuras y datos de prueba.
